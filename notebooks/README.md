# Notebooks

Notebook analisis (Jupyter) untuk proyek EduSmart, dijalankan berurutan:

1. **01_data_cleaning.ipynb** — handling missing value, duplikasi, dan outlier (lihat `docs/analysis_checklist.md`)
2. **02_eda.ipynb** — exploratory data analysis: distribusi, tren, completion rate per segmen
3. **03_feature_engineering.ipynb** — pembuatan fitur turunan (completion_flag, week1_progress, access_hour, dll)
4. **04_correlation_analysis.ipynb** — uji korelasi rating vs completion rate, analisis prediktif minggu pertama

> Notebook aktual belum disertakan di repo contoh ini — struktur ini menunjukkan urutan kerja yang direkomendasikan sesuai `docs/roadmap.md`.
